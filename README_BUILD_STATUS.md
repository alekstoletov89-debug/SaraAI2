# SaraAI2 — промежуточная локальная сборка без голосового образца

## Важно перед запуском\nЭта ветка пока является промежуточной текстовой сборкой. Она не восстанавливает прежнюю полную архитектуру с `core/`, GigaAM/E5 и голосовым агентом. Не считать её полной голосовой SaraAI2.\n\n## Диагностика и память проекта\n- Для сбора информации одним двойным щелчком запусти `CHECK_SARA2.bat`. Он создаст `SARA2_DIAGNOSTICS.txt`; этот файл можно прислать для разбора ошибок.\n- История проблем, известных ошибок, окружения и команд проверки сохранена в `SARA2_PROJECT_MEMORY.md`. Перед следующими изменениями сверяйся с этим файлом.\n\n## Установка
1. Скачай ZIP этой ветки и распакуй папку.
2. Дважды щёлкни INSTALL_SARA2.bat. Скрипт создаст .venv, установит зависимости и создаст ярлык SaraAI2 на рабочем столе.
3. Для диалога нужна установленная Ollama и локальная модель qwen3.5:9b. Они не включены в архив.
4. Запускай через ярлык SaraAI2.

## Возможности
- Локальный диалог через Ollama / Qwen.
- Сохранение последних 12 сообщений в memory/dialogue_history.json.
- Открытие калькулятора, блокнота, проводника, диспетчера задач, панели управления и некоторых настроек Windows.
- Просмотр списка процессов и системной информации.

## Ограничения
Это отдельный автономный текстовый режим, а не восстановление полной прежней архитектуры SaraAI2. Голосовой режим, голос жены, GigaAM, E5-поиск и расширенный набор Windows-инструментов пока не включены. Установщик не загружает Ollama и языковую модель автоматически. Работу микрофона, GPU и модели нельзя проверить через GitHub; нужна проверка на компьютере после установки.

Опасные действия (удаление файлов, выключение/перезагрузка, завершение процессов) намеренно не реализованы.
